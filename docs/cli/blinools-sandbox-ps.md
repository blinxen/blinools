# NAME

blinools-sandbox-ps - List all sandboxes and their state

# SYNOPSIS

**blinools sandbox ps** \[OPTIONS\]

# DESCRIPTION

List all sandboxes and their state

# OPTIONS

**-c**, **--config** *\<FILE\>*  
Use FILE as the project configuration.

This replaces ./blinools.toml. The global configuration is read first.

**-v**, **--verbose**  
Increase logging verbosity

**-q**, **--quiet**  
Decrease logging verbosity

**-h**, **--help**  
Print help (see a summary with '-h')
