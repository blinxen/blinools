# NAME

blinools-wip-pr - This command is not yet implemented

# SYNOPSIS

**blinools wip-pr** \[OPTIONS\] \<BRANCH_NAME\>

# DESCRIPTION

This command is not yet implemented.

It accepts arguments but creates no worktree or branch.

# OPTIONS

**-t**, **--branch-type** *\<BRANCH_TYPE\>*  
Specify an optional branch type

**-n**, **--task-number** *\<TASK_NUMBER\>*  
Specify an optional task number

**-c**, **--config** *\<FILE\>*  
Use FILE as the project configuration.

This replaces ./blinools.toml. The global configuration is read first.

**-v**, **--verbose**  
Increase logging verbosity

**-q**, **--quiet**  
Decrease logging verbosity

**-h**, **--help**  
Print help (see a summary with '-h')

\<*BRANCH_NAME*\>  
Specify the branch name
